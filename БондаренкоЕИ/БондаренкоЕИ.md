## Что было сделано

Я прошёл в тренажёре Git Mastery (https://gitmastery.me/) все три уровня сложности: Beginner, Advanced, Mastery, а это больше, чем требовалось в задании (там обязателен только Advanced). Скриншоты пройденных уроков приложены в файлах.

## Пройденные темы

**Beginner**
- Introduction to Git
- File Operations
- Working with Branches
- Remote Repositories

**Advanced**
- Merging Branches
- Git Workflows
- Team Collaboration
- Undoing Commits
- Git Stash

**Mastery**
- Разрешение конфликтов слияния при объединении нескольких веток
- Git hooks и автоматизация проверок качества (pre-commit)
- Аварийное исправление: `cherry-pick`, аннотированные теги (`git tag -a`), отправка тегов (`git push --tags`)
- Исправление последнего коммита (`git commit --amend`)

## Освоенные команды

`git init`, `git status`, `git add`, `git commit`, `git log`, `git show`, `git branch`, `git switch` / `git checkout`, `git merge`, `git rebase`, `git reset`, `git stash`, `git cherry-pick`, `git tag`, `git push`.

## Что я освоил

Я научился уверенно работать с ветками: создавать их, объединять через `merge` и `rebase` и разрешать конфликты, когда несколько человек меняют один и тот же файл. Разобрался, как откатывать и исправлять изменения (`reset`, `commit --amend`, `stash`), а также как переносить отдельные коммиты через `cherry-pick`. Понял, что такое Git hooks и как с их помощью автоматически проверять код перед коммитом. Кроме того, я отработал fork-workflow: форк репозитория, отдельная ветка, коммит, push и создание Pull Request.
